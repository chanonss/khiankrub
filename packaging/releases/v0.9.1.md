**KhianKrub (เขียนครับ) 0.9.1**, Chanon Sarasuk's fork of WordCraft by the ArtCraft team, adapted for Thai and English writing. Built from this repository for Windows and Mac (Apple silicon and Intel).

## What is new since v0.9.0

- **Icons in right-click menus.** Document and table actions, including Insert, Delete and AutoFit submenus, use the app's original ribbon icons. Shortcuts and disabled actions remain visible.
- **More list-number actions.** Right-click a number to restart at 1, define a multilevel list, or increase/decrease its indent. Mac Control-click works too.
- **Report a problem.** The button beside Share opens the developer's form with the version and platform already filled in. It does not include document content.
- **File works in an empty window.** After leaving the Start screen, File still opens New and Open.
- **A Mac DMG installer**, with a drag-to-Applications shortcut. The universal zip remains available.

## Install on Mac

1. Download **KhianKrub-0.9.1-macos-universal.dmg**, open it, and drag **KhianKrub** onto **Applications**. It runs on Apple silicon and Intel Macs. The universal zip is an alternative: unzip it and drag the app into Applications.
2. Replace the older copy if asked; your settings are kept.
3. The app is ad-hoc signed and is not notarized by Apple. If macOS blocks it, open **System Settings › Privacy & Security › Open Anyway** after trying to open it. On systems that offer it, Control-click the app and choose **Open**.

## Install on Windows

1. Download **khiankrub-0.9.1-windows-x64.msi** and open it. It replaces an older KhianKrub installation.
2. The installer is unsigned. If Windows shows “Windows protected your PC”, use **More info › Run anyway**.
3. Follow the installer, accepting the licence and the Windows permission prompt. KhianKrub appears in the Start menu.

For use without installation, download **khiankrub-0.9.1-windows-x64-portable.zip**, unzip it, and open **KhianKrub.exe**.

## Limits

- Mac: macOS 11 or later. Windows: Windows 10 or 11, 64-bit (x64).
- Many dialogs and Options pages are still in English when the interface is Thai.
- Thai document fonts, including TH Sarabun New and the SIPA families, are read from locally installed fonts and are not included in these packages.
- Google Drive files use the existing system file picker, including files made available by Google Drive for desktop.

## Code signing policy

Windows packages are unsigned. Mac packages are ad-hoc signed and not notarized. See the [code signing policy](https://github.com/chanonss/khiankrub#code-signing-policy).
