**KhianKrub (เขียนครับ) 0.9.2**, Chanon Sarasuk's fork of WordCraft by the ArtCraft team, adapted for Thai and English writing. Built from this repository for Windows and Mac (Apple silicon and Intel).

## What is new since v0.9.1

- **Documents with links print.** A document with a hyperlink or a table of contents failed to print from the desktop app; it prints now. PDFs you save keep their links.
- **Up and down buttons for character spacing** in the Font dialog and Modify Style › Font, in 0.1 pt steps.
- **Thai fonts read clearly in the font menu.** Each entry is sized by its letter height, so TH Sarabun New and the other SIPA fonts are no longer tiny.
- **Lines ending in Shift+Enter stretch** under Justify and Thai Distributed, as in Word.
- **Closer to Word:** headings from other programs show in the Navigation pane; table-of-contents page numbers are PAGEREF fields; Format Painter works on a double-clicked word; Increase and Decrease Font Size keep mixed sizes mixed; Table Properties applies to every selected row, column and cell; Crop on a picture's right-click menu; regular-expression groups in Replace; Standard-encrypted Word files open with their password.
- **Steadier:** bounds for damaged fonts, Word files and very long layouts; faster PDF export; macOS launch arguments are no longer opened as files, and a file that won't open is named on the status bar with the reason.

## Install on Mac

1. Download **KhianKrub-0.9.2-macos-universal.dmg**, open it, and drag **KhianKrub** onto **Applications**. It runs on Apple silicon and Intel Macs. The universal zip is an alternative: unzip it and drag the app into Applications.
2. Replace the older copy if asked; your settings are kept.
3. The app is ad-hoc signed and is not notarized by Apple. If macOS blocks it, open **System Settings › Privacy & Security › Open Anyway** after trying to open it. On systems that offer it, Control-click the app and choose **Open**.

## Install on Windows

1. Download **khiankrub-0.9.2-windows-x64.msi** and open it. It replaces an older KhianKrub installation.
2. The installer is unsigned. If Windows shows “Windows protected your PC”, use **More info › Run anyway**.
3. Follow the installer, accepting the licence and the Windows permission prompt. KhianKrub appears in the Start menu.

For use without installation, download **khiankrub-0.9.2-windows-x64-portable.zip**, unzip it, and open **KhianKrub.exe**.

## Limits

- Mac: macOS 11 or later. Windows: Windows 10 or 11, 64-bit (x64).
- Many dialogs and Options pages are still in English when the interface is Thai.
- Thai document fonts, including TH Sarabun New and the SIPA families, are read from locally installed fonts and are not included in these packages.
- Google Drive files use the existing system file picker, including files made available by Google Drive for desktop.

## Code signing policy

Windows packages are unsigned. Mac packages are ad-hoc signed and not notarized. See the [code signing policy](https://github.com/chanonss/khiankrub#code-signing-policy).
